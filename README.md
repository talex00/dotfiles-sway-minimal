# dotfiles-sway-minimal

Минималистичное окружение на **Sway** (Wayland): светлая тема, нулевые гэпы, тонкие
рамки и никакого лишнего кода в самих конфигах. Раскладывается через GNU Stow.

## Стек

| Роль | Пакет |
| --- | --- |
| Оконный менеджер | sway + autotiling (спиральный split) |
| Терминал | foot |
| Панель | waybar (вертикальная, слева) |
| Лаунчер и dmenu | fuzzel |
| Уведомления | mako |
| Блокировка, обои, idle | swaylock-effects, swaybg, swayidle |
| Файловый менеджер | Thunar |
| Буфер обмена | wl-clipboard + cliphist |
| Скриншоты | grim + slurp |
| Цветовая температура | gammastep |
| Батарея | batsignal |
| Диктовка | Handy (хоткей держит sway) |
| Tray | nm-applet, blueman-applet |
| Shell | fish + fastfetch |

## Установка

```bash
yay -S sway swaylock-effects swayidle swaybg autotiling waybar foot fuzzel mako \
    thunar stow fish fastfetch grim slurp gammastep batsignal wl-clipboard \
    cliphist jq playerctl brightnessctl ddcutil network-manager-applet blueman \
    nwg-displays inter-font adwaita-icon-theme

cd ~/dotfiles-sway-minimal
chmod +x sway/.config/sway/scripts/*.sh sway/.config/sway/scripts/*/*.sh
stow sway foot fuzzel mako fish xfce
```

`swaylock-effects` заменяет обычный `swaylock` — менеджер пакетов предложит замену,
это ожидаемо. Пакет `sway` раскладывает сразу `~/.config/sway`, `~/.config/waybar`
и `~/.config/swaylock`.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `Super + T` / `E` / `D` | терминал / файлы / лаунчер |
| `Super + Q` / `F` | закрыть окно / полный экран |
| `Super + B` / `P` | float / sticky |
| `Super + V` | история буфера обмена |
| `Super + W` | смена обоев |
| `Super + N` | ночной режим (gammastep) |
| `Super + L` | блокировка экрана |
| `Super + ]` | меню скриптов |
| `Ctrl + Super` | диктовка: вкл/выкл запись в Handy |
| `Super + Shift + S` | скриншот области в буфер |
| `Super + Ctrl + S` | скриншот области в файл и буфер |
| `Super + ←↑↓→` | фокус, с `Shift` — переместить окно |
| `Super + 1…0` | воркспейс; `+Shift` — перенести окно, `+Ctrl` — перенести молча |
| `Alt + Tab` | следующее окно |
| `Super + Space` | раскладка us/ru |
| `Ctrl + Alt + Del` | меню завершения сессии |
| `Ctrl + Super + Alt + R` | reload sway и waybar |

Буквенные и цифровые бинды объявлены с `--to-code`, поэтому работают в любой раскладке.

## Экран блокировки

Обои те же, что на рабочем столе, без блюра и прочих эффектов. По центру тонкое белое
кольцо, внутри — чёрный с большой прозрачностью, чтобы время читалось на любой
картинке. Время крупное, дата под ним мелкая. Ввод символа подсвечивается зелёным,
стирание — красным.

Путь к обоям в конфиг swaylock не прописать: там нет ни подстановки команд, ни
раскрытия `~`. Поэтому блокировка идёт через `scripts/lock.sh`: он читает тот же
`~/.config/sway/wallpaper`, что и swaybg, и передаёт картинку в `swaylock -i`.

Главное, что нужно знать при правках `sway/.config/swaylock/config`, — размеры
связаны жёстко:

| Что | Чем задаётся | Сейчас |
| --- | --- | --- |
| кольцо | `indicator-radius` | `340` |
| время | `font-size` | `240` |
| дата | `indicator-radius / 6`, своей опции нет | ≈ `57` |
| `verifying` / `wrong` / `cleared` | `font-size` | скрыты прозрачным цветом |
| индикатор раскладки | `font-size` | выключен через `hide-keyboard-layout` |

Отсюда несколько неочевидных следствий:

- **дату нельзя увеличить или уменьшить отдельно** — она растёт только вместе с
  кольцом. Её ширину подгоняют форматом `datestr`, а не размером шрифта:
  `%a, %-d %B` даёт «пн, 24 августа», а `%A` — «понедельник» и строку вдвое шире;
- **время нельзя увеличить, не увеличив кольцо**: строка шириной больше
  ≈ `0.73 × indicator-radius` за кольцо уже вылезает. Из этого же следует потолок
  отношения «время / дата» — примерно `4.4`, дальше время просто не помещается в круг;
- служебные надписи и бокс с раскладкой тоже масштабируются от `font-size`, поэтому
  при крупных часах `verifying` шире круга, а раскладка занимает пол-экрана. Первое
  убрано прозрачными `text-ver-color` / `text-wrong-color` / `text-clear-color`
  (состояние и так читается по цвету кольца), второе — `hide-keyboard-layout`;
- прозрачность круга — последние две цифры в `inside-color` (`66` ≈ 40%, `99` ≈ 60%).

`font-size` не умножается на масштаб вывода, а радиус — умножается. На дисплее с
`scale` больше 1 пропорции времени и даты поедут, размер придётся подобрать заново.

Шрифт часов — `Inter` (пакет `inter-font`). Если не хочется лишнего шрифта в системе —
поменяйте `font=Inter` на `font=JetBrains Mono`.

## Диктовка (Handy)

Wayland не даёт приложениям перехватывать глобальные хоткеи, поэтому комбинацию
держит sway и переключает запись сигналом `SIGUSR2` — так советует сама
документация Handy. Собственная настройка хоткея внутри Handy при этом не
участвует вообще: комбинацию задаёт только конфиг sway.

Ключевой момент — **сигналу нужен живой процесс**. Поэтому Handy стоит в автозапуске,
а сама команда умеет его поднять:

```
set $handy pkill -USR2 -xi handy || Handy.AppImage || $HOME/.local/bin/Handy.AppImage || notify-send "Handy" "Handy.AppImage не найден"
```

- `pkill -USR2 -xi handy` — переключить запись у запущенного процесса. `-x` требует
  точного имени, `-i` добавляет регистронезависимость: у AppImage дочерний процесс
  называется по внутреннему бинарнику и регистр может быть любым;
- `Handy.AppImage` — запуск, если процесса нет. Первое нажатие поднимает приложение,
  следующее уже включает запись;
- явный `$HOME/.local/bin/...` нужен потому, что `~/.local/bin` попадает в `PATH`
  только через `fish_add_path` из `config.fish`, то есть лишь внутри fish. Если sway
  запущен не из fish, короткого имени в `PATH` не будет;
- уведомление в конце означает, что AppImage лежит где-то ещё — поправьте путь.

Биндов два, и это не опечатка:

```
bindsym Ctrl+Super_L      exec $handy
bindsym Ctrl+$mod+Super_L exec $handy
```

sway сравнивает маску модификаторов на точное равенство, а `Super` здесь
одновременно и модификатор, и сама клавиша: к моменту нажатия `Super_L` бит `Mod4`
может быть уже выставлен. Какая из двух строк совпадёт — зависит от версии sway;
совпасть одновременно они не могут, так что двойного переключения не будет.

В настройках Handy нужен режим toggle, а не push-to-talk: сигнал переключает
запись, а не держит её.

Проверить, что приложение вообще живёт:

```bash
pgrep -a -i handy
```

## Мониторы

В git конфига мониторов нет: на разных машинах разные выходы, а `git pull` затирал бы
локальную раскладку. `~/.config/sway/monitors.conf` живёт только на машине и лежит
в `.gitignore`. Подключается глобом, а не прямым путём:

```
include ~/.config/sway/*.conf
```

Так sway молча пропустит include, если файла нет, — на свежей системе не будет
ошибки конфига.

```bash
swaymsg -t get_outputs                          # имена выходов и режимы
nwg-displays -o ~/.config/sway/monitors.conf    # расставить мышкой → Save
swaymsg reload
```

Встроенный `eDP-1` гасится или включается на старте скриптом
`scripts/monitors-fallback.sh` по наличию внешнего `DP-1` — это единственное, что
осталось привязано к именам выходов. Для автоматики при док/отстыковке лучше
поставить **kanshi** и описать профили — тогда скрипт можно удалить совсем.

## Обои

Путь по умолчанию зашит в `config` (`~/Pictures/Wallpapers/frieren_meme.webp`) — замените
на свой. `Super + W` открывает выбор из `~/Pictures/Wallpapers`; выбранный путь сохраняется
в `~/.config/sway/wallpaper`, в git не попадает и подхватывается экраном блокировки.

## Скрипты

`Super + ]` показывает плоский список `scripts/**/*.sh` через fuzzel. Скрипты из подпапок
требуют sudo и поэтому запускаются в терминале.

| Скрипт | Что делает |
| --- | --- |
| `lock.sh` | блокировка теми же обоями, что на рабочем столе |
| `wallpaper.sh` | выбор и применение обоев |
| `screenshot.sh` | скриншот области в файл и буфер |
| `powermenu.sh` | logout / suspend / reboot / shutdown |
| `brightness.sh up\|down` | яркость: brightnessctl для eDP-1, DDC/CI для внешнего |
| `monitors-fallback.sh` | eDP-1 вкл/выкл по наличию DP-1 |
| `power_management/power-profile.sh` | TDP + boost + EPP: eco / balanced / performance |
| `power_management/toggle_health_mode.sh` | лимит заряда 80% (Acer WMI) |

## Заметки

- В sway нет dwindle-тайлинга — спираль даёт демон `autotiling`.
- Скруглений, блюра и прозрачности в sway нет: активное окно видно по голубой рамке.
  Нужны эффекты — поставьте **SwayFX**, конфиг совместим.
- Заголовок окна в панели повёрнут штатным `"rotate": 90` (нужен waybar ≥ 0.10).
  На более старой версии верните `custom/window` со скриптом.
- Палитра foot лежит в `[colors-dark]`, хотя она светлая: с foot 1.26 секция `[colors]`
  устарела и спамит предупреждением в каждом окне, а `[colors-dark]` — секция,
  активная по умолчанию. Если когда-нибудь понадобится переключение тем — добавьте
  `[colors-light]` и `initial-color-theme=light`.
- Иконки в лаунчере требуют явной `icon-theme` в `fuzzel.ini`. `icons-enabled` включён
  по умолчанию, но тема по умолчанию — `hicolor`, а он почти пустой, поэтому список
  выглядит вообще без иконок. Сейчас стоит `Adwaita`; любая другая тема — это просто
  имя папки в `/usr/share/icons` (например `Papirus` из `papirus-icon-theme`).
- `Ctrl + Super` срабатывает по нажатию Super при зажатом Ctrl, поэтому при наборе
  `Ctrl + Super + Alt + R` диктовка тоже дёргается. Нажмите ещё раз, чтобы выключить,
  или перевешайте reload на другую комбинацию.
