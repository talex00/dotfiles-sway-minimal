## Происхождение `look.sh`

Архив до модернизации
`~/.local/state/sway-minimal/backups/dotfiles-before-20261112.tar.gz` содержит
версию SHA-256 `cfdfe9706b4afcfc81d98b061c5838f0dedcd4dc0f4ac6f695b506d33ce78b73`.
Diff архив → активная версия показывает добавленные в первой итерации команды
`help`, `status`, `themes`, `styles`, `doctor` и обработку неизвестной команды.
Diff активная → новая показывает только две правки, сделанные для v2:

1. Определение `f_cursor_size`, чтобы renderer читал одноимённый state-файл;
   при отсутствии файла сохраняется fallback 30. Если такой файл существует,
   обычный legacy-генератор тоже начнёт его учитывать.
2. При `SWAY_MINIMAL_RENDER_ONLY=1` генерация выходит до GTK/gsettings/D-Bus.
   Без этой переменной сохраняется существующий путь применения GTK.

Признаков отдельных независимых пользовательских изменений в diff активная →
новая не обнаружено; история Git отсутствует, поэтому происхождение определяется
по резервной копии, фактическому diff и журналу предыдущих работ, а не коммитам.
Оба изменения сохранены; активный файл не заменялся.

## Пользовательские настройки и ограничения

При чтении были выбраны `everforest-light`, рамка 2, smart borders on, gaps 0,
`edge`, стиль `cards`, панель `top`, курсор `ModernXP`. В `sway/look` размер
курсора 30, в GTK 3/4 — 24; автоматически они не объединяются. Значения могут
измениться, поэтому preflight перед применением необходимо повторить.

Разрешение в JSON — точечное техническое согласование, а не разрешение на
применение. Отдельные команды Theme Engine, сохранение rollback и headless
проверялись, однако production-интеграция v2 и реальная миграция не выполнены.
Не запускайте `--apply` для рабочего HOME до отдельного разрешения и полной
проверки интеграции; подробности в MIGRATION.md и INTEGRATION.md.
